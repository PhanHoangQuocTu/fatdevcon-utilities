Quick start

Start with exact math, then import only the helpers you need.

Every public utility is a named export, so applications can make focused imports.

Exact decimal math in TypeScript

import { divide, summary } from "@fatdevcon/utilities";

summary(0.1, 0.2); // 0.3
divide("1", "3", { precision: 5 }); // "0.33333"
summary("100000000000000000000000", "1");
// "100000000000000000000001"

Format values for a real user

import { formatCurrency, formatInTimeZone } from "@fatdevcon/utilities";

formatCurrency("12345678901234567890.129", "USD");
// "$12,345,678,901,234,567,890.13"

formatInTimeZone(new Date("2026-01-15T12:00:00Z"), "Asia/Ho_Chi_Minh");

Examples

Common developer tasks with real package APIs.

These examples answer useful JavaScript and TypeScript utility problems without introducing unexported abstractions.

How to group data in JavaScript

import { groupBy } from "@fatdevcon/utilities";

const byRole = groupBy([
  { name: "An", role: "dev" }, { name: "Binh", role: "qa" },
], (user) => user.role);
// { dev: [{ name: "An", ... }], qa: [{ name: "Binh", ... }] }

How to retry an async operation

import { withRetry } from "@fatdevcon/utilities";

const loadConfig = () => fetch("/config.json").then((response) => response.json());
const value = await withRetry(loadConfig, {
  retryCount: 3,
  delay: ({ count }) => 200 * 2 ** count,
  shouldRetry: ({ error }) => error.name !== "AuthError",
});

How to format a timezone-aware date

import { getTimeZoneOffset, formatInTimeZone } from "@fatdevcon/utilities";

const instant = new Date("2026-01-15T12:00:00Z");
getTimeZoneOffset(instant, "Asia/Ho_Chi_Minh", { unit: "hours" }); // 7
formatInTimeZone(instant, "Asia/Ho_Chi_Minh", "en-GB", {
  dateStyle: "short", timeStyle: "short", hourCycle: "h23",
}); // "15/01/2026, 19:00"

FAQ

Before you add another utility dependency.

Does this package support TypeScript?

Yes. It ships ESM and CommonJS type definitions, and public option and utility types are exported alongside functions.

Can it handle bigint and very large numeric strings?

Yes. Exact numeric utilities accept number, bigint and decimal strings. Return kinds follow the documented input rules.

Does it work in Node.js, Bun and browsers?

It supports Node.js 18+ and Bun 1.1.34+. Formatting and timezone helpers use standard Intl capabilities, so output follows the runtime locale data.

Is this a replacement for every utility library?

No. It is a focused collection of typed helpers for exact decimal arithmetic, formatting, text, collections, async flow and algorithms. Import the functions that fit your application.
